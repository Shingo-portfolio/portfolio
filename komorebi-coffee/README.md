# こもれび珈琲 コーディング見本

架空のカフェ「こもれび珈琲」のデザイン画像（ChatGPT で生成）から、HTML / CSS でコーディングした見本です（2ページ）。

- ページ: `index.html`（トップ）, `menu.html`（メニュー）
- 色・文字・余白などの値は `css/tokens.css` にまとめ、`css/components.css` はその値だけを使っています
- パソコンとスマホの幅に対応しています
- デザイン: `design/top.png`（トップ）, `design/menu.png`（メニュー）
- 仕上がりの画面: `screenshots/`（幅 1440px と 375px）
